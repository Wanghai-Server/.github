# This is WangHai Server!

## Server Overview
*Wanghai Server (abbreviated as WHS)* is a Minecraft Java edition server centered on survival redstone, running version *1.21.10-Fabric*. The server has keep inventory enabled, and the seed is *-1865289266 (wanghai_commune)*. The community is friendly, emphasizing player cooperation and automated machine construction.

## Server History
- *Season 1 (Wanghai Commune)*: Originally founded by *stevendjr*, aiming to build a cooperative survival community modeled after a "People's Commune." Later, *1410happy_* took over as the server owner.  
- *Season 2 (Wanghai Server)*: The current season, continuing from *Season 1*. Since July 17, 2026, *1410happy_* has been the server owner, providing physical machine and technical support, while *stevendjr* has transitioned to co-owner.  
- The server has experienced two member splits: the first occurred when *1410happy_* briefly left and later returned; the second happened when *PeaFlower_9331* stepped down as an admin and founded *the CCU server*.

## Featured Gameplay
The server focuses on survival redstone, featuring a *Fully Automatic Item Sorting and Storage System (abbreviated as Full-Items)*, an extensive rail transit network (with multiple lines already built, totaling tens of thousands of meters in length), various efficient mob farms and resource farms, and multiple player settlements (such as Snow Town and Lingyue New District).
